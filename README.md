# COMP 206 Practice

My semester practice in Bash and C.

## Organization

- bash/hackerrank: HackerRank Bash exercises
- bash/personal: Independent Bash practice
- c/hackerrank: HackerRank C exercises
- c/leetcode: LeetCode solutions in C
- c/personal: Independent C practice
- notes: Concepts, mistakes, and takeaways

## Practice method

1. Attempt the exercise independently.
2. Run it and check edge cases.
3. Record the approach and what I learned.
4. Commit a meaningful checkpoint.

## Semester focus

- Bash practice alongside the Bash portion of COMP 206.
- C fundamentals in preparation for the C portion.
- Continued C practice as lectures introduce new topics.
