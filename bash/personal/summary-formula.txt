Conditionals:
1. if [ $x -ge $y ]; then
	echo....
   elif [...]; then
	echo...
   else; then
	echo...
   fi

2. for ((i=1; i<100; i++)); do
	echo...
   done

3. while ...; do
   done

4. switch or case
	case $1 in 
		Pattern1)
		echo"..."
		;;
		
		Pattern2)
		echo"..."
		;;

		Pattern3 | Pattern4)   --> either 3 or 4, same echo
		echo "..."
		;;
		
		*)           --> else/default
		echo
		;;
	esac      	--> inverse of case

6. READ USAGE
a) Calling read for the first time calls first line
--> subsequent calls resume where you left from
--> in "read n" read got to stdin and gives stdin to n

b) while read -r date time level message
--> 2026-09-20 14:02:11 INFO Server started
--> var1 = 2026-09-20
--> var2 = 14:02:11
--> var3 = INFO
--> var4 = the rest of the message

c) modifiers:
--> -p "Giving a prompt"
# -n 3 --> Make read stop after 3 characters
# -N 3 --> Read only 3 characters, ignore others
# -r --> respects backlash
